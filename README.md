# TaskFlow – Smart Student Productivity Hub

TaskFlow is a full-stack student productivity web application developed as part of my Full Stack Development internship at CodeOrbit Tech.

It helps students manage their daily tasks, organize priorities, track progress, and maintain productivity through a simple and attractive dashboard.

## Features

- User Registration
- Secure Login
- Session-based Authentication
- Logout
- Personalized Dashboard
- Create Tasks
- Complete / Uncomplete Tasks
- Delete Tasks
- Task Categories
- Task Priorities
- Due Dates
- Task Search
- All / Active / Completed Filters
- Task Statistics
- Progress Percentage
- Dark Mode / Light Mode
- Responsive Design
- Toast Notifications

## Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Authentication & Security
- bcrypt
- express-session
